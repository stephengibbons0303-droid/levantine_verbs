# Quiz Sentence Frames — Option C Format (Verbs 11–20)

**Convention reminder:**
- `frame_before`: only for contextual/negative particles (ma, shū, etc.), never ra7/bedde/3am
- `frame_after`: empty string `""` for standalone questions
- Imperative: only 3 persons (ínta/ínti/íntu)
- Participle: engine maps person → m/f/pl form from verbs.json

## Notes for This Batch

### Edge cases handled:
- **V13 row 8:** `frame_before = "ba3dak ma"`, `frame_after = ""` — standalone "didn't you eat lunch yet?" pattern. Same convention as V4-row-8.
- **V14 row 5:** Uses `lēzim` (must/should) as frame_before — this is a modal particle like bedde/ra7, but since it's less common than the engine-handled ones, it goes in frame_before. Engine doesn't auto-insert lēzim.
- **V15 row 5:** Uses `kirmēl ma` (so that...not) as frame_before — negative purpose clause.
- **V16 row 4:** Uses `3am` in frame_before because the sentence has a second clause (`w-ma 7ada 3am byírudd`). Normally 3am is engine-handled, but here the whole sentence structure needs it baked in.

### Vocab pool additions needed:
- **il-7sēbēt** (accounts) — used in V15, was in our suggested additions but not yet formally in pool
- None others — all vocab pulls from approved pool

### Verbs with limited imperative usage:
- **V14 (tfēda):** "Avoid!" is unnatural as a standalone command. Used negative imperative (ma + imperfect) in row 8 instead.
- **V17 (tmánna):** "Hope!" is unusual as a command but grammatically valid. Kept it.
